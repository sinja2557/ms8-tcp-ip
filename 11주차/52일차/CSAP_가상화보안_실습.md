# 0. 시작하기 전에

## 0.1 푸는 방법

1. 문제는 **회색 상자**에 있습니다. 상자 안의 '할 일'을 그대로 하면 됩니다.
2. 답은 상자 바로 아래 **빈 칸이나 표**에 씁니다. 회색으로 채워진 줄은 **샘플(예시 답)** 입니다.
3. '힌트'에 몇 개를 찾아야 하는지, 어디를 보면 되는지 적어 두었습니다.
4. 보기에서 고르는 문제는 **번호(①, ② …)** 로 답합니다.

## 0.3 알아 둘 기준 — 해설서 9장 요점

| **항목** | **해설서가 요구하는 것** |
| --- | --- |
| 9.1.1 가상자원 관리 | 생성·변경·회수 절차와 책임자 승인, 주기 점검. 이미지·스냅샷은 등록 절차·담당자·정해진 저장 장소·공유 금지·안전성(백신·패치)·불필요 서비스 제거·배포 무결성 검증 |
| 9.1.2 가상자원 회수 | 회수 시 백업·접속로그까지 완전 삭제, 이용자의 삭제 확인 요청에 응답 |
| 9.1.3 가상자원 모니터링 | 이미지·스냅샷 해시·체크섬으로 무결성 확인, 같은 하이퍼바이저 VM 간 메모리 공유 금지, 생성·이동·삭제·복사가 승인된 작업만 이루어지는지 모니터링, 손상 시 이용자에게 지체 없이 통지(책임자 연락처·손상 범위·피해) |
| 9.1.4 하이퍼바이저 보안 | 최신 업데이트, 관리 기능 2-Factor 인증·접근 IP 제한·전용 관리 단말, 별도 관리망, 접속·작업 로그 보관과 주기 분석, 운영자 최소 권한, 비인가 SW 설치 금지, 백신과 감염 대응 |
| 9.1.5 공개서버 보안 | TLS 1.2 이상, 백신·패치, 불필요한 서비스·테스트 페이지·에러 정보 노출 제거, DMZ 배치, 주기 취약점 점검, 접속 이력 저장·점검 |
| 9.2.1 악성코드 통제 | 백신·웹쉘 탐지 등 최신화, 감염 시스템 즉시 사용 중단·격리, 전파 여부 점검, 서비스 영향 시 이용자 통지 |
| 9.2.2 인터페이스·API 보안 | API 목록 관리, 연 1회 이상 취약점 분석 — 타인 데이터 접근, 권한을 넘는 접근, 데이터 과다 노출, 과도한 리소스 사용, 잘못된 설정. SaaS는 상위 서비스(IaaS) API와 이용자 API를 모두 식별 |
| 9.2.3 데이터 이전 | 전용회선·VPN 등 암호화 채널, 수동 이전 시 매체 암호화·무결성 확인·접근 인력 식별 |
| 9.2.4 가상 SW 보안 | 출처·제작자가 분명한 SW만. 출처 불명·지원 종료(EOL)·라이선스 없는 SW 설치 금지, 제작사 패치 적용 |
